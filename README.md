# Genetic Simulation — HTML и React

## О проекте

Этот проект — интерактивная **«Генетическая лаборатория»**, в которой генетический алгоритм демонстрируется на наглядной 2D-модели машин. В репозитории представлены две версии одного проекта: исходная HTML/CSS/JavaScript-версия и адаптированная версия на React + Vite. Структура двух вариантов и назначение основных каталогов описаны ниже.

### Что такое генетические алгоритмы

**Генетический алгоритм** — это метод поиска и оптимизации, вдохновлённый принципами естественного отбора и эволюции. Вместо того чтобы сразу искать одно идеальное решение, алгоритм работает с популяцией кандидатов. Для каждого поколения оценивается качество кандидатов, более удачные решения получают больше шансов передать свои свойства следующему поколению, а мутации и другие генетические операции добавляют разнообразие.

Упрощённо цикл выглядит так:

1. создаётся начальная популяция случайных решений;
2. каждое решение проверяется в соответствии с целевой функцией (fitness);
3. лучшие решения отбираются для дальнейшего размножения;
4. из них формируются новые решения с помощью скрещивания и/или мутаций;
5. новый цикл повторяется до получения достаточно хорошего результата или достижения заданного числа поколений.

### В чём преимущество генетического подхода

Генетические алгоритмы особенно полезны для задач, где пространство возможных решений большое, функция качества сложная, а классические методы оптимизации трудно применить напрямую. Их сильная сторона — способность исследовать множество вариантов одновременно и постепенно находить хорошие решения без необходимости заранее задавать точный путь к оптимуму.

При этом генетический алгоритм не гарантирует нахождение глобально лучшего решения за конечное число итераций: результат зависит от структуры задачи, параметров алгоритма и случайных факторов. Поэтому проект особенно полезен как визуальная демонстрация того, как **эволюционный поиск постепенно улучшает популяцию решений**.

### Что моделируется в проекте

В проекте моделируется **популяция 2D-машин**, поведение которых оценивается в физической среде. Для симуляции используется Canvas и существующий физический/генетический движок проекта. Машины выступают в роли кандидатов-решений: каждое поколение представляет новый набор вариантов, а генетический алгоритм использует результаты предыдущего поколения для формирования следующего.

Таким образом, пользователь может наблюдать не только итоговый результат, но и сам процесс эволюции: как меняется популяция, как отбираются более успешные варианты и как за последовательность поколений алгоритм пытается улучшить поведение машин.

## Вариант 1 — HTML

Это сохранённый текущий проект без перевода на React. Оригинальные файлы движка, физики, генетического алгоритма и Canvas находятся в `html-version/`.

### Локальный запуск

Для локального запуска лучше использовать простой HTTP-сервер, а не открывать `index.html` через `file://`.

Например, из каталога `html-version`:

```bash
cd html-version
python -m http.server 8000
```

Откройте:

```text
http://localhost:8000
```

Также подойдёт любой статический сервер.

### Docker

```bash
cd html-version
docker build -t genetic-simulation-html .
docker run --rm -p 8080:80 genetic-simulation-html
```

Откройте `http://localhost:8080`.

## Вариант 2 — React + Vite

React-версия сохраняет существующий симуляционный движок и Canvas, но запускает его внутри React-компонента `LegacySimulation`. Это позволяет постепенно переносить отдельные части интерфейса и логики на React, не ломая рабочую физику и генетический алгоритм.

### Требования

- Node.js 20+
- npm 10+ (рекомендуется)

### Установка и запуск в режиме разработки

```bash
cd react-version
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

### Production-сборка

```bash
cd react-version
npm install
npm run build
```

Результат находится в:

```text
react-version/dist/
```

Проверить production-сборку локально:

```bash
npm run preview
```

### Docker

```bash
cd react-version
docker build -t genetic-simulation-react .
docker run --rm -p 8081:80 genetic-simulation-react
```

Откройте `http://localhost:8081`.

---

## Запуск обоих вариантов через Docker Compose

Из корня репозитория:

```bash
docker compose up --build
```

После сборки:

- HTML: `http://localhost:8080`
- React: `http://localhost:8081`

Остановить:

```bash
docker compose down
```

## Что сохранено при переносе на React

React-версия не переписывает математическую модель симуляции заново. Оригинальный `bundle.js`, `box2d.js`, `seedrandom.js`, стили и DOM-разметка симуляции сохранены, а React отвечает за оболочку и жизненный цикл подключения legacy-движка.

Компоненты:

- `AppHeader` — React-шапка приложения.
- `LegacySimulation` — React-мост к оригинальной DOM/Canvas-симуляции.
- `App` — корневой компонент приложения.

Такой подход снижает риск изменения поведения симуляции и оставляет возможность следующего этапа: переносить панели управления, графики, метрики и Canvas на отдельные React-компоненты.

## Примечания

1. HTML-версия является исходным вариантом проекта.
2. React-версия требует HTTP-сервера/Vite: загрузка legacy-фрагмента выполняется через `fetch()`.
3. Для Docker используется Nginx как статический web-сервер.
4. Проект не требует backend-сервера: симуляция выполняется в браузере.
